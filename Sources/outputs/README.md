# Market Mood — Analysis Outputs

This directory stores the generated visualizations and experimental results produced by the Market Mood analysis.

## Visualizations

The project generates figures illustrating:

- Historical S&P 500 closing values.
- Daily return distributions.
- Rolling market volatility.
- K-Means market regime assignments.
- Comparison-based market conditions derived from K-Means and hierarchical clustering.

## Experimental Findings

The analysis evaluated three clustering configurations:

| Experiment | Best Silhouette Score |
|---|---:|
| Original K-Means | 0.369 |
| Reduced-Feature K-Means | 0.332 |
| Hierarchical Clustering | **0.380** |

The algorithms produced an Adjusted Rand Index of **0.584**, with 130 observations assigned differently.

These disagreements were analyzed to investigate distinctions between milder declines and more pronounced market stress.

## Final Visualization

The final market-condition visualization distinguishes:

- **Growth / Stable:** 900 observations
- **Mild Decline / Transitional:** 130 observations
- **Pronounced Decline / Stress:** 205 observations

These are descriptive categories derived from comparing two clustering models, not three clusters generated by a single algorithm.
