# Market Mood — Project Reports

This directory contains the academic documentation for **Market Mood: Discovering Stock Market Regimes Using Unsupervised Machine Learning**, developed for the Fall 2026 Data Mining course at Georgia State University.

## Documentation

- **Project Proposal:** Introduces the research objectives, proposed methodology, and development plan.
- **Mid-Project Report:** Summarizes data collection, preprocessing, feature engineering, exploratory analysis, and preliminary clustering results.
- **Final Project Report:** Presents the completed experiments, model comparisons, visualizations, findings, limitations, and conclusions.

## Project Summary

Market Mood investigates historical S&P 500 market behavior using K-Means and hierarchical clustering to identify distinct market conditions.

The final analysis evaluates clustering quality, feature selection, and agreement between algorithms.

For implementation details and results, see the [main project README](../README.md).
